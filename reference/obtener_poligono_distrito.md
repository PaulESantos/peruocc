# Obtiene el poligono de un distrito especifico en el Peru

Obtiene el poligono de un distrito especifico en el Peru

## Usage

``` r
obtener_poligono_distrito(distrito, departamento = NULL, provincia = NULL)
```

## Arguments

- distrito:

  Nombre del distrito (requerido).

- departamento:

  Nombre del departamento (opcional, para resolver ambiguedades).

- provincia:

  Nombre de la provincia (opcional, para resolver ambiguedades).

## Value

Un objeto sf con el poligono del distrito.
