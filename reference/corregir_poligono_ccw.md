# Corrige la orientacion de un poligono sf para que el anillo exterior sea CCW y los anillos interiores (huecos) sean CW.

Corrige la orientacion de un poligono sf para que el anillo exterior sea
CCW y los anillos interiores (huecos) sean CW.

## Usage

``` r
corregir_poligono_ccw(poly)
```

## Arguments

- poly:

  Objeto de tipo polygon de sf (lista de matrices).

## Value

Objeto de tipo polygon corregido.
