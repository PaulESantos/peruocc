# Package index

## All functions

- [`asegurar_orientacion_antihoraria()`](https://paulesantos.github.io/peru_species_project/reference/asegurar_orientacion_antihoraria.md)
  : Asegura que todas las geometrias de un objeto sf tengan orientacion
  antihoraria (CCW)
- [`buscar_especies_distrito()`](https://paulesantos.github.io/peru_species_project/reference/buscar_especies_distrito.md)
  : Realiza una busqueda combinada de especies en un distrito usando
  GBIF e iNaturalist
- [`buscar_gbif_por_poligono()`](https://paulesantos.github.io/peru_species_project/reference/buscar_gbif_por_poligono.md)
  : Busca ocurrencias de especies en GBIF dentro de un poligono de
  distrito
- [`buscar_inat_por_poligono()`](https://paulesantos.github.io/peru_species_project/reference/buscar_inat_por_poligono.md)
  : Busca ocurrencias de especies en iNaturalist dentro de un poligono
  de distrito
- [`corregir_poligono_ccw()`](https://paulesantos.github.io/peru_species_project/reference/corregir_poligono_ccw.md)
  : Corrige la orientacion de un poligono sf para que el anillo exterior
  sea CCW y los anillos interiores (huecos) sean CW.
- [`graficar_ocurrencias()`](https://paulesantos.github.io/peru_species_project/reference/graficar_ocurrencias.md)
  : Grafica el mapa de ocurrencias sobre el poligono del distrito
- [`obtener_poligono_distrito()`](https://paulesantos.github.io/peru_species_project/reference/obtener_poligono_distrito.md)
  : Obtiene el poligono de un distrito especifico en el Peru
- [`peruspecies_data_dir()`](https://paulesantos.github.io/peru_species_project/reference/peruspecies_data_dir.md)
  : Configure the directory used for package artifacts
- [`poligono_a_wkt()`](https://paulesantos.github.io/peru_species_project/reference/poligono_a_wkt.md)
  : Convierte un objeto sf a formato WKT (Well-Known Text) para
  consultas GBIF
- [`simplificar_para_api()`](https://paulesantos.github.io/peru_species_project/reference/simplificar_para_api.md)
  : Simplifica un poligono sf o genera su bounding box si es muy
  complejo para cumplir con el limite de longitud de caracteres de WKT.
- [`simplificar_poligono()`](https://paulesantos.github.io/peru_species_project/reference/simplificar_poligono.md)
  : Simplifica un poligono de tipo sf usando proyecciones UTM
- [`verificar_y_configurar_entorno()`](https://paulesantos.github.io/peru_species_project/reference/verificar_y_configurar_entorno.md)
  : Verify package dependencies
