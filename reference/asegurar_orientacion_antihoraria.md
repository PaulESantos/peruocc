# Asegura que todas las geometrias de un objeto sf tengan orientacion antihoraria (CCW)

Asegura que todas las geometrias de un objeto sf tengan orientacion
antihoraria (CCW)

## Usage

``` r
asegurar_orientacion_antihoraria(sf_obj)
```

## Arguments

- sf_obj:

  Objeto sf.

## Value

Objeto sf con orientaciones corregidas.
